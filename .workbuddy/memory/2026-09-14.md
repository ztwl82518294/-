## 修点击门店图片"添加图片"没反应

用户反馈：line-edit 页面点击"添加图片"虚线框无响应。排查：
1. **WXML/CSS 错位**：`form-item-photos` 是 flex 容器但没设 `flex-wrap:wrap`，`.photos-hint` 文字被挤到 `.photo-add` 右边空白处，DOM 顺序靠后可能影响 `.photo-add` 的命中区
   - 修法：把 `.photos-hint` 移到 `.photos-grid` 内部（grid 已有 `flex-wrap:wrap`），让 hint 借 `flex-basis:100%` 自然换行到第二行
2. **真错误**：用户实机弹出"调用相册失败：xxx" —— 根因是 `app.json` 的 `requiredPrivateInfos: ["chooseLocation"]` **缺 `chooseMedia` 声明**。基础库 2.33+ 强制要求，未声明会被静默拒绝并触发 fail
   - 修法：app.json 加 `"chooseMedia"`，同时 `permission.scope.album` 加相册用途描述（用户授权时能看到 "用于上传门店展示图片"）
3. **JS 兜底**：`choosePhotos` 失败时（排除主动取消）弹 toast 暴露真实原因；同时检测到 `wx.chooseMedia` 不存在时（基础库 < 2.21）回退到 `wx.chooseImage`

- 关键提示：**改 app.json 必须重编译 + 重启小程序才会生效**（仅编译不重启不会重新读 app.json）
- 74 项测试全过；JS 语法 check 通过；app.json JSON 格式 valid

## ⚠️ 错把 chooseMedia 加进 requiredPrivateInfos → 撤回

用户反馈错误：`requiredPrivateInfos[1] 字段需为 chooseAddress,chooseLocation,choosePoi,getFuzzyLocation,getLocation,onLocationChange,startLocationUpdate,startLocationUpdateBackground`

**重要纠正**：`requiredPrivateInfos` 在 lib 3.x 范围只有 **8 个地理 API**，**`chooseMedia` / `chooseImage` 不在里面**。相册/摄像头的权限处理走：
- `app.json` 的 `permission.scope.album`（给描述用，被 chooseMedia/chooseImage 读取）
- 调用前的 `wx.requirePrivacyAuthorize`（lib 2.33+，对应 iOS 14.5+/Android 12+ 隐私模式）
- 自定义 `wx.onNeedPrivacyAuthorization` 桥接（合规要求，可选）

修复：
- **撤掉** `requiredPrivateInfos` 里加的 `"chooseMedia"`（是错的，白名单不接受）
- line-edit 的 `choosePhotos` 加 `wx.requirePrivacyAuthorize` 调用：lib 2.33+ 走授权后调 `chooseMedia`，旧版直接调
- 修复 toast 优先级 bug：`'调用相册失败：' + msg || '未知错误'` → `'调用相册失败：' + (msg || '未知错误')`
- 14 项测试全过；JS 语法 OK；app.json JSON valid

**教训**：以后涉及微信小程序敏感 API，必须先确认 `requiredPrivateInfos` 白名单范围（仅 8 个地理 API），相册/摄像头权限通过 `permission.scope.album` + `wx.requirePrivacyAuthorize` 处理

### 调用相册的完整正确链路

```js
// 1. app.json
"permission": { "scope.album": { "desc": "用于上传门店展示图片" } }

// 2. 调用前（line-edit/index.js）
if (wx.requirePrivacyAuthorize) {  // lib 2.33+
  wx.requirePrivacyAuthorize({
    success: () => wx.chooseMedia({...}),
    fail: () => wx.chooseMedia({...})   // 兜底再试一次
  });
} else {
  wx.chooseMedia({...});                // 旧版直接调
}

// 3. fallback：旧版 wx.chooseImage
```

### 用户还需做的关键一步

去微信小程序**官方后台**（mp.weixin.qq.com）→ 设置 → 第三方设置 → 用户隐私保护指引 → **添加"相册（仅写入）"**用途说明并审核通过。否则 `wx.requirePrivacyAuthorize` 不会有弹窗也不会走流程，真机调用相册会被系统静默拒绝。

## errMsg 揭晓：api scope is not declared in the privacy agreement

用户实机 errMsg：`chooseMedia:fail api scope is not declared in the privacy agreement`

**根因**：调用 chooseMedia 的服务端校验**后台隐私协议未声明**该 scope。`app.json.permission.scope.album` 只影响客户端弹窗描述，不替代后台隐私协议声明。

**正确链路（验收）**：
1. ✅ app.json `permission.scope.album` 有描述（客户端弹窗用）
2. ⏳【关键】**小程序管理后台** → 设置 → 第三方设置 → 用户隐私保护指引 → 开发者收集信息说明里加"图片/视频/音频" → 用途：上传门店展示图片 → 保存并提交审核（1-2 工作日）
3. ⏳ 审核通过后**重新发布**小程序（包括开发者上传新版代码），新版发布后隐私协议才生效
4. ⏳ 真机**首次**点"添加图片" → 弹微信官方"小程序使用你的相册"授权弹窗 → 用户点允许 → 才能选图

**代码处理**：把 line-edit `requirePrivacyAuthorize` 的 fail 不再静默重试 chooseMedia（重试也是同样错误），改为 `wx.showModal` 明确告知管理员后台修复路径。重要：wx.requirePrivacyAuthorize 的 `success` 回调也**不能保证** chooseMedia 一定能成功——服务端会再校验一次隐私协议。所以即便加完 requirePrivacyAuthorize 还需要等后台声明审核通过。
