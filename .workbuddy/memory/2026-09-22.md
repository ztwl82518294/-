### ★ 本机 git 的怪毛病：远程跟踪引用存不住
`git fetch` 报「new branch」，但 `refs/remotes/origin/*` **不落盘**；
`git update-ref refs/remotes/origin/main <SHA>` **返回 0 却什么也不写**（`git show-ref` 里没有），
`.git/refs/remotes` 始终是空目录。⇒ `git status` 会显示 `[origin/main: gone]`、`git log origin/main` 报
`Not a valid object name`。**这是沙箱对 `.git` 写入的限制，不是仓库坏了。**
- **别被 `[gone]` 吓到**：判断「有没有推上去」只看 `git ls-remote origin`（问服务端），
  或直接用 commit SHA 查（`git ls-tree -r <SHA>`）。
- 要比较远程内容时，用 `git fetch --no-tags origin <SHA>` 再对 `FETCH_HEAD` 操作。

### 问题 1：首页所有按钮点击没反应（根因：隐形遮罩）

因果链（已完整验证）：
1. `components/privacy-modal/index.json` 是 `styleIsolation: "isolated"`
   ⇒ **`app.wxss` 的全局 `.mask` 进不来**
2. `privacy-modal/index.wxss` **漏写 `.mask`** ⇒ 遮罩零尺寸、零背景，**视觉上完全看不见**
3. `onReject()` **没有 `setData({ visible: false })`** ⇒ 用户点「不同意」后，
   `.pm-root`（`position:fixed; inset:0; z-index:1000`）**永久留在 DOM 里覆盖整屏**
4. ⇒ 首页所有按钮的点击被它吃掉

**为什么症状是「有时好有时坏」**：取决于用户当初点的是「同意」还是「不同意」——
点同意会关弹窗，一切正常；点不同意则遮罩永驻，整页失灵。

修复 4 处：
- `privacy-modal/index.wxss` 补 `.mask`（`position:absolute; inset:0; background:rgba(15,15,15,.6)`）
- `privacy-modal/index.js` 的 `onReject()` 加 `this.setData({ visible: false })`
- `privacy-modal/index.wxml` 遮罩 `bindtap="noop"` → `bindtap="onReject"`（多一层保险，点遮罩即关）
- `components/city-picker/index.wxss` **同款缺陷一并修**（同样 isolated + 同样漏 `.mask`）

> **立为规则**：组件内遮罩/弹层样式一律自备，**不要依赖 `app.wxss` 的全局 `.mask`**。
> 排查「按钮没反应」的顺序：透明遮罩 → bindtap 笔误 → 跳转目标未注册 → 被覆盖 → catchtap 截断。

## 隐私弹窗「按钮点了没反应」（当晚，第二次踩弹窗坑）

用户发截图：弹窗正常显示（标题、8 条 items、footer、协议链接、不同意/同意并继续都在），
但**点什么都不动**。这一轮先排除的：
- `bindtap` 与 JS 方法名全部对得上；`pages/privacy/index` 已在 `app.json` 注册
- `onReject` 已经有 `setData({visible:false})`（上一轮补的）
- 全站没有比 `z-index:1000` 更高的层（`app.wxss` .mask 900 / .sheet 901、city-picker 950、correction 800）
- `app.js` 无全局拦截，首页 wxss 无全屏覆盖层

**定位到两个层叠/定位隐患**（都是「看得见却点不到」的经典成因）：
1. `.mask` 与 `.pm-panel` 都只写 `position:absolute`、**都没写 z-index**，靠 DOM 顺序决胜；
   而 `.pm-panel` 用 `top:50% + transform:translateY(-50%)` 做垂直居中，
   **transform 会创建独立层叠上下文** ⇒ 命中区域可能和肉眼所见不一致。
2. 全站用了 `inset: 0` 简写 —— 低版本内核不认会塌成 0 尺寸。

**改法**（components/privacy-modal 的 wxss/wxml/js + city-picker 同款 + app.wxss）：
- 遮罩 `z-index:0`、面板 `z-index:1` **写死**，不靠 DOM 顺序
- 面板**改用父级 flex 居中**，去掉 transform（少一个 transform 就少一层层叠上下文）
- `inset` 全部改四边写开
- 滚动区加 `max-height` 硬上限，保证按钮区永不被挤出可视范围
- 兜底四件套：右上「×」多一条退出路径；`onAgree` 改**先 setData 关窗再落存储**
  （副作用挂了也关得掉）；跳转协议页加 `fail` 提示；「不同意」补 `:active` 按下反馈

**护栏**：check-project.js 新增第 12 类「弹层层叠检查」——
禁 `inset` / 弹层类定位必写 `z-index` / isolated 组件用 `.mask` 必须自备。
**反向验证**：临时插 `inset: 0` 和「定位无 z-index」两条探针，都能被抓到，验证完删除。
