## 意外收获：修好一个形同虚设的检查工具

清理中实跑 `check-requires.js`，发现它**长期报假失败**（把注释里的用法示例当真实依赖）：

```
❌ test\framework.js:12  ->  ../framework
```
（第 12 行是注释 `* 在套件里：const { ... } = require('../framework');`）

**假失败比不检查更糟** —— 会让人直接忽略整个检查。修复：加 `stripComments()`，
**剥注释但保留字符串**（`require` 的路径就在字符串里），且**用等长空白替换 → 行号不变**。

> 中途踩坑：第一版把字符串也抹掉了，输出变成「✅ 全部 **0 处** 相对 require 路径均有效」——
> 扫描形同虚设。**剥注释绝不能连字符串一起剥。**

修复后：`✅ 全部 64 处相对 require 路径均有效`，并**并入 `scripts/check-project.js`（8 类 → 10 类）**。
