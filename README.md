# 物流专线查询小程序 (v3.1)

基于**微信云开发**的物流专线查询平台。用户可查询/搜索专线、查看详情（含发货/到货地址）、拨号、导航、收藏。首页支持公告与 10 个可售卖广告位。管理员通过隐藏后台实时管理全部内容。

> **当前状态**：v3.1.0 合规版 —— 已下线"发布找线需求"功能，平台**不收集用户手机号/姓名等个人信息**，内置《用户服务协议》与《隐私政策》。

---

## 一、功能清单

### 👤 用户端
| 功能 | 说明 |
|------|------|
| 专线查询 | 省市区选择器，支持全国所有省市 |
| 智能搜索 | 按名称/公司/城市模糊搜索（云端过滤） |
| 专线详情 | 时效、价格、标签、**发货地址、到货地址** |
| 一键拨号 | 直接联系物流公司（多号码可选） |
| 地图导航 | 发货点微信内置地图导航 |
| 分享专线 | 分享给微信好友 |
| 收藏专线 | 云端收藏，跨设备同步 |
| 查询历史 | 本地保存最近 20 条 |
| 首页公告 | 顶部滚动公告栏 |
| 广告位 | 首页 10 个公司卡片式广告位 |
| 协议与政策 | 《用户服务协议》《隐私政策》入口（我的页） |

### 🛠 管理端
| 功能 | 说明 |
|------|------|
| 权限控制 | OpenID 白名单，仅管理员可见 |
| 数据看板 | 专线总数实时统计 |
| 专线管理 | 增删改查、上下架、JSON 导入/导出 |
| 广告管理 | 编辑 10 个广告位（公司名/区域/数字） |
| 公告管理 | 编辑首页公告 |

## 四、隐私合规说明

- **不收集**：手机号、联系人姓名等个人身份信息（"发布找线需求"功能已于 v3.1 下线）。
- **云端存储**：仅收藏的专线内容 + openid（用于收藏关联与管理员识别）。
- **本地存储**：查询历史（仅手机缓存，不上传）。
- 协议全文见小程序「我的 → 用户服务协议 / 隐私政策」。
- 微信公众平台「用户隐私保护指引」需声明：用户身份信息（openid）、位置信息（发货点设置）。
