# 专线批量导入说明（万股级数据）

## 快速上手

1. 从 **`专线导入模板-空白版.json`**（干净空白，含填写说明）或 `专线导入模板.json`（含完整示例）复制结构，准备数据文件（JSON 数组，每条一个专线对象）
2. 小程序管理后台 → 专线管理 → 「⬆ 导入」→ 从微信聊天记录选择 .json 文件
3. 确认后自动**分批导入**（每批 200 条，自动显示进度）

> 空白版模板首条是 `_说明` 字段（以 `_` 开头，导入时自动忽略，不影响数据），从第 2 条起才是可填写记录。

## 文件要求

- **格式**：JSON 数组；文件建议每份 ≤ 2000 条（过大会导致选文件/解析卡顿，可拆多份依次导入）
- **必填字段**：`title`、`fromCityName`、`toCityName`（缺任一字的记录会被跳过）
- **导入即全新记录**：文件中的 `id`/`_id` 会被忽略并重新生成，重复导入同一文件会产生重复数据

## 字段说明

| 字段 | 必填 | 说明 |
|------|------|------|
| title | ✅ | 线路名称（展示用），如「XX物流 济南-广州 专线」 |
| companyName | 建议 | 物流公司名称（VIP 按公司批量开通依赖此字段精确匹配） |
| fromCityName / toCityName | ✅ | 出发/到达城市，**自然写法即可**（"济南市"“广州"均可），服务端自动规范化为标准城市字段 `fromCity`/`toCity` 用于搜索索引 |
| toAreas | 可选 | 到达辐射区，**逗号分隔字符串**（推荐，好写）或 JSON 数组均可，如 `广州全境,佛山,东莞`；支持"XX全境"写法 |
| fromOutlets | 建议 | **发站网点**（推荐写法）：一行一个网点，格式 `地址 \| 电话`，多个电话用逗号分隔；也支持对象数组 `[{"addr":"…","phone":"…"}]`。详情页按 `1 地址+电话 / 2 地址+电话` 逐组展示 |
| toOutlets | 建议 | **到站网点**，写法同上 |
| fromAddress / toAddress | 可选 | 提货/送货地址。**填了网点就不用填**（服务端由网点反推）；不填网点时，多个地址用换行分隔 |
| latitude / longitude | 可选 | 发货点经纬度（地图导航用），可后续在编辑页地图选点补充 |
| toLatitude / toLongitude | 可选 | 到货点经纬度（收货方导航用），可后续在编辑页地图选点补充 |
| aging | 可选 | 时效，如「2-3天」 |
| priceDesc | 可选 | 参考价格描述 |
| lineType | 可选 | 业务类型，如「整车/零担」 |
| fromPhone | ✅ | **发站电话**（发货点联系电话），多个用逗号分隔，如 `13800000000,0531-82518294`。**不填网点时必填** |
| toPhone | ✅ | **到站电话**（到货点联系电话），多个用逗号分隔；与发站相同可填同一个号码。同上 |
| phone | 不填 | 兼容字段，导入时自动生成（= 发站电话），无需写在文件里 |
| tags | 可选 | 标签，**逗号分隔字符串**或 JSON 数组均可，如 `直达,天天发车` |
| isVip | 可选 | 1=会员（缺省 0；旧数据 isVip=1 无到期时间时自动补 1 年） |
| certified | 可选 | 1=已认证 |
| status | 可选 | 1=上架，0=下架（缺省 1） |

## 网点配对规则（地址 ↔ 电话）

详情页按「**1 地址+电话 / 2 地址+电话**」逐组展示，配对来源优先级：

1. **有网点字段**（`fromOutlets` / `toOutlets`）：按写入顺序精确配对，**推荐**。一个网点可挂多个电话。
2. **没有网点字段**（老数据 / 简版模板）：按 `地址[0]↔电话[0]`、`地址[1]↔电话[1]` **下标对位**；数量不等时多出的一方单独成组（只显示有的那一半，信息不丢）。

三种写法等价，服务端统一归一为 `[{addr, phone}]`：

```json
// ① 对象数组（最清晰，推荐）
"fromOutlets": [
  { "addr": "济南盖家沟物流园A区12号", "phone": "13800000000" },
  { "addr": "济南历城区华山街道某某仓库", "phone": "0531-82518294,13900000001" }
]

// ② 字符串数组：每行 "地址 | 电话"
"fromOutlets": [
  "济南盖家沟物流园A区12号 | 13800000000",
  "济南历城区华山街道某某仓库 | 0531-82518294"
]

// ③ 整段文本：换行分行，行内用 | 分隔（Excel 粘贴友好）
"fromOutlets": "济南盖家沟物流园A区12号 | 13800000000\n济南历城区华山街道某某仓库 | 0531-82518294"
```

> 注意：**行分隔用换行/分号，不用逗号**——地址内部常含逗号（如「天桥区北环路，建邦大桥南」）。
> 一行只写一个值时，纯数字且数字位 ≥7 判为电话，否则判为地址。

服务端会自动保持 `网点 ↔ fromAddress/fromPhone` 一致（给了网点就反推地址电话串；没给就由地址电话重建网点），因此：
- **导入**：用 `fromOutlets` 精确配对，不用再填 `fromAddress`/`fromPhone`
- **管理端单条编辑**：编辑页仍按「地址 + 电话」填，保存后服务端按下标对位重建网点（若某网点挂了多个电话，建议在导入模板里就用 `fromOutlets`，避免编辑后配对位移）

## 万股级注意事项

1. **先建索引再导入**：按 `cloudfunctions/createIndexes/README.md` 清单建好 `fromCity`、`fromCity+status` 等索引，导入后搜索才走索引
2. **城市名尽量写规范城市名**（地级市/省/直辖市），区县级可写入 `toAreas` 辐射区，搜索时区县输入会自动归属到上级城市
3. **导入后验证**：随机抽几条在用户端搜索确认能命中；再用管理端搜索确认列表可见
4. **单条修改**：VIP 到期、上下架等在管理列表逐条操作；同一公司的线路 VIP 用「按公司批量开通」
