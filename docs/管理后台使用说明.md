# 管理后台使用说明

> 面向日常运营。**后台不在小程序里**，它是跑在你自己电脑上的一个网页，只有你能打开。

---

## 一、怎么进后台

### 方式 1：双击启动（推荐）

在项目根目录双击 **`start-admin.bat`**。

会自动做三件事：起服务 → 等服务真的能连上 → 打开浏览器。
窗口里会显示网址，别关这个窗口 —— **关掉窗口 = 关掉后台**。

### 方式 2：命令行启动

```bash
node scripts/start-admin.js
```

效果和双击一样。加 `--no-open` 则只起服务、不自动开浏览器。

### 方式 3：手动启动（知道自己在做什么时用）

```bash
node admin/server.js
```

然后自己打开 **http://127.0.0.1:8787**。

### 打不开怎么办

| 现象 | 原因与处理 |
|---|---|
| 提示「Node.js was not found」 | 没装 Node.js。去 https://nodejs.org 装 16 以上版本，装完重新双击 |
| 启动超时（15 秒连不上） | 数据目录多半被写坏了。跑 `node scripts/export-seed.js --admin-only` 重建，再启动 |
| 浏览器没自动弹出 | 手动访问 http://127.0.0.1:8787 |
| 页面打不开、连不上 | 后台没在跑（窗口被关了）。重新双击 `start-admin.bat` |
| 提示端口被占用 | 后台已经开着了。直接用已有的那个，不要重复启动 |

## 二、账号

- 默认账号：**`admin` / `admin12345`**
- **第一次登录后立刻改密码**：右上角「改密码」

改密码页在右上角用户名旁边。改完会立即退出，用新密码重新登录。

**忘了密码**：后台没有「找回密码」（没有邮箱也没有手机号，做了也是假的）。
真忘了就删掉 `admin/data/admins.json`，下次启动会重建默认账号，然后马上改掉。

## 三、页面导览

| 页面 | 干什么 |
|---|---|
| 总览 | 数据规模、待审核纠错、有没有一致性问题 |
| 公司 | 物流公司的增删改查 |
| 线路 | 线路（出发地-目的地）的增删改查 |
| 线路公司 | ★ 关联维护。**时效、是否直达、发车频率都挂在这一层** |
| 公告栏 | ★ 首页顶部滚动播放的公告 |
| 优质线路 | ★ 首页「优质线路推广」卡片 |
| 纠错审核 | 用户在小程序里提交的纠错，采纳 / 驳回 / 待定 |
| 批量导入 | 用 Excel / CSV 批量导入公司 |
| 数据质量 | 缺电话多少家、超 90 天没更新多少条、有没有悬空数据 |

## 四、改完的数据怎么到小程序里

这是最容易搞混的一点，务必先看懂这张图：

```
你在后台改的  →  admin/data/*.json  →  导出 .data/*.jsonl  →  云开发控制台导入  →  小程序读云数据库
   （本地）           （本地副本）          （中间文件）            （云端）            （用户看到的）
```

**在后台改完，小程序不会立刻变。** 还要走两步：

```bash
node scripts/export-seed.js          # 1. 导出成 .data/*.jsonl
```

然后到**微信云开发控制台 → 数据库**，把 `.data/` 里对应的 jsonl 导入进去。

八张表：公司 / 线路 / 线路公司 / 城市 / 纠错 / 管理员 / **公告** / **推广位**。

> 如果只想重置后台、不动小程序：跑 `node scripts/export-seed.js --admin-only`，
> 它只重建 `admin/data/`，`admins.json`（账号）不受影响。

## 五、几个常用操作

### 发一条首页公告

公告栏 → 新建公告。三条硬规则：

1. **正文不能空** —— 点开要有内容
2. **跳转路径必须以 `/pages/` 开头**，或者干脆留空。
   **不要填外链** —— 小程序里跳不出去，用户点了没反应
3. 想让某条排前面，把排序值调小

### 上一条优质线路

优质线路 → 新建。**推广位只选一条已经存在的线路**，再写角标（≤8 字）和推荐理由（≤60 字）。
同一条线路只能推一次。公司数不用你填，小程序会现场去查，避免「写着 8 家、点进去 3 家」。

### 批量导入公司

批量导入 → 上传 `.xlsx` 或 `.csv` → 确认字段映射 → 看错误预览 → 确认导入。

**预览阶段不会写任何数据**，放心传。错误行会带 Excel 行号，跳过不影响其他行。
老格式 `.xls` 不支持，在 Excel 里另存为 `.xlsx` 再传。

导入模板（不需要登录就能下）：http://127.0.0.1:8787/api/import/template

### 给一家公司加第二个发站 / 到站网点

**「发站（提货点）」「到站（送货点）」一个方块里，一行就是一个网点：**

- 在地址框里**按 Enter** —— 自动换到下一行（已是最后一行就新增一行）
- 或点方块底部的 **「＋ 添加网点」** 按钮
- 每行右边的 **×** 删掉这一行（只剩一行时点 × 是清空）
- 每个方向最多 **10** 个网点；地址和电话**一一对应**，别错位

> 注意：地址框本身是单行的，长地址会左右滚动，录入时一路输完即可，不需要在框内折行。

### 改一条公司的时效

时效不在「公司」页改，也不在「线路」页改 —— 在**「线路公司」**页改。
因为同一家公司跑济南→广州是 2 天、跑济南→乌鲁木齐是 5 天，
时效是「谁跑哪条线」的属性，必须按关联分别存。

## 六、改了后台却不生效怎么办

后台是把页面模板读进内存里运行的，**改完代码必须重启进程**，光刷新网页没用。
顺序是：

1. **关掉那个黑窗口**（正在跑后台的那个，Ctrl+C 或直接关掉）
2. **重新双击 `start-admin.bat`**
3. **浏览器按 Ctrl + F5 硬刷新**（普通刷新可能还在用缓存）

> 如果你双击时看到提示「这个后台是之前启动的进程，跑的还是旧代码」，
> 就说明旧进程还占着端口 —— 先关掉它再重新双击。

## 七、数据安全上的两条硬规矩

1. **后台只监听 127.0.0.1**，不对外网开放。别把它改到 `0.0.0.0`，
   它是整个系统唯一的写入口。
2. **`admin/data/` 是你正在用的工作副本**。它不入版本库（`.gitignore` 已排除），
   因为里面会是真实的公司电话和地址。别把它提交上去。

如果后台数据被改乱了：

```bash
node scripts/export-seed.js --admin-only
```

从唯一数据源 `data/seed-data.js` 重建，账号不受影响。
